# ML Experiment Tracking with Weights & Biases (W&B)

A beginner-friendly Python project demonstrating machine learning experiment tracking using Weights & Biases (W&B).

## Features
- Logs training metrics such as **accuracy** and **loss**
- Tracks **hyperparameters** including learning rate and epochs
- Visualizes experiment results using the W&B dashboard
- Demonstrates basic **MLOps experiment tracking workflow**

## Tools & Technologies
- Python
- Weights & Biases (W&B)
